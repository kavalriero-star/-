# 룬북 개인용

AI와 함께 웹소설을 쓰는 개인용 집필실이다. 작가는 방향을 정하고, **글은 Claude**, **그림은 ChatGPT**가 맡는다.
앱은 설정·줄거리·인물 상태·떡밥·문체를 기억해 두었다가 AI를 부를 때마다 빠짐없이 다시 알려 준다. AI는 API 키가 아니라 이 PC에 로그인된 **구독**을 쓴다.

- 장르: 판타지, 헌터물, 무협, 역사물(한국 시대물 포함), 그리고 이들의 혼합형
- 시작 위저드: 세계관, 힘의 체계, 세력, 주인공, 조연·적대자, 관계, 첫 사건을 AI 후보 중에서 고르거나 고쳐 쓰며 만든다
- 함께 쓰기: 장면 비트를 적으면 Claude가 장면 초안을 쓰고, 이어 쓰기·다듬기·번갈아 쓰기도 된다. 초안은 받아들일 때만 원고에 들어간다
- 그림: 장면 일러스트, 세계 지도, 도시·던전, 캐릭터·빌런·몬스터, 아이템. 화풍과 인물 외형을 고정해 일관되게 그린다
- 기억 장치: 호출마다 무엇을 넣었는지 "기억 장부"로 보여 주고, 쓴 뒤 사망 인물 등장이나 처음 보는 이름을 알려 준다

## 실행 (Windows)

1. [Node.js](https://nodejs.org) 22 이상을 설치한다.
2. 글: [Claude Code](https://code.claude.com)를 설치하고 터미널에서 `claude`를 한 번 실행해 구독 계정으로 로그인한다.
3. 그림(선택): Codex CLI를 설치하고 `codex login`으로 ChatGPT 계정에 로그인한다. 없으면 프롬프트를 복사해 ChatGPT에서 그린 뒤 가져오는 수동 방식을 쓴다.
4. `룬북.bat`을 더블클릭한다. 브라우저가 열리고, 검은 도우미 창을 닫으면 앱이 꺼진다.
5. 처음에는 "모의 AI"로 연결되어 있다. **AI 연결** 화면에서 글을 Claude로, 그림을 ChatGPT(Codex)로 바꾼다.

원고와 설정은 `내 문서`가 아니라 사용자 폴더의 `룬북데이터`에 열린 형식(JSON·Markdown)으로 저장된다. 다른 위치를 쓰려면 `룬북.bat --data D:\원하는\폴더`처럼 실행한다.

### 처음 한 번: 환경 점검

`check-env.bat`을 실행하면 한글 경로, 한글 입력 전달, 프로세스 종료, `claude`·`codex` 설치·로그인을 점검하고 `app/check-env-result.json`을 만든다. 기본 점검은 구독 한도를 쓰지 않는다.
`check-env.bat --live`는 Claude·Codex를 각각 한 번 짧게 불러 실제 출력 형식을 저장한다(한도를 조금 씀). 결과 파일을 개발 쪽에 전달하면 남은 미검증 항목을 닫을 수 있다.

## 알려진 한계

- 이 저장소의 개발 환경(Linux)에서는 Windows를 실행할 수 없어서, Windows 동작은 `check-env` 결과로 확인해야 한다.
- 구독 계정을 개인 PC의 공식 CLI로 호출하는 것은 약관이 "막지 않는다"고 할 뿐 적극적으로 허용한 용도는 아니다(설계서 8.6절). 정책이 바뀌면 API 키 방식으로 바꿀 수 있게 어댑터를 분리해 두었다.
- 그림은 ChatGPT 사용 한도를 글보다 3~5배 빨리 쓴다(Codex 문서 기준). 몇 장까지 되는지는 공개되어 있지 않다.
- `codex exec`의 출력에는 그림 정보가 없어 저장 폴더(`%USERPROFILE%\.codex\generated_images`)에서 찾는다. 폴더 이름 규칙은 소스 분석 결과이고 실측 전이다.
- AI 모델은 실수할 수 있다. 기억 장치는 잊을 일을 줄이고 쓴 뒤 대조로 모순을 찾지만, 0으로 만들지는 못한다.
- 집필 화면은 일반 텍스트 영역이다. 본문 속 이름 밑줄과 여백 경고 점은 에디터 시험(M2) 뒤에 붙인다.

# 룬북 개인용

웹소설 작가 한 명이 쓰는 집필 보조 프로그램이다. AI(Claude, ChatGPT)는 API 키가 아니라 본인 구독 계정을 쓴다.

- 장르: 판타지, 헌터물, 무협, 역사물(한국 시대물 포함), 그리고 이들의 혼합형
- 시작 위저드: 세계관, 주인공, 조연·적대자를 AI와 한 단계씩 만든다
- 집필 중 추천: 맥락(지금 이야기가 어디인지), 방향(다음 전개 선택지), 표현(어떻게 쓸지)을 필요할 때 버튼으로 받는다
- 원고는 이 PC의 폴더에만 저장한다. AI는 본문을 대신 쓰지 않는다

## 현재 상태: 설계 완료 · 시안 단계 (M0)

| 항목 | 상태 |
|---|---|
| 설계 명세서 | 전문가 5인 회의 결과 통합 + 독립 검증 2건 반영, v0.2 (`docs/`) |
| 시안 | 클릭 가능한 HTML 7화면, AI 응답은 모의 데이터 (`prototype/index.html`) |
| 실제 AI 연결 | 아직 없음. 로컬 도우미(`server.mjs`)부터 만들 예정 (설계서 9절 M1) |

## 시안 보는 법

`prototype/index.html`을 브라우저로 열면 된다. 빌드와 설치가 필요 없다. 글꼴은 인터넷에서 불러오고, 없으면 시스템 글꼴로 표시된다.
시안에서 저장은 하지 않는다. "AI 연결" 화면의 시뮬레이터로 한도 도달·로그인 만료·도우미 꺼짐 같은 오류 화면도 볼 수 있다.

## 알려진 한계

- Claude 연결은 `claude -p`를 이 컨테이너(Linux)에서 실행해 확인했다. Windows에서는 아직 실행해 보지 않았다.
- ChatGPT(Codex CLI) 연결은 소스와 문서로만 확인했고 실행하지 못했다.
- 구독 계정을 개인 PC의 공식 CLI로 비대화 호출하는 것은 약관이 "막지 않는다"고 할 뿐 적극적으로 허용한 용도가 아니어서 회색지대다. 정책도 6월과 10월에 두 번 바뀌었다. 설계서 8.6절에 근거와 안전 범위, 조회일을 적었다.
- `--json-schema` 구조화 출력과 도구 차단(`--tools ""`)은 함께 쓸 수 없다. M1 첫 주에 시험하고 안 되면 앱 쪽 검증기를 쓴다(설계서 8.3절).
- Claude Code의 `--bare`가 앞으로 `-p`의 기본값이 될 예정이라, 그렇게 되면 구독 로그인으로 쓰는 `-p`가 깨질 수 있다. CLI 버전을 고정한다.
- 검증용으로 `claude`를 여러 번 실행해 구독 주간 한도 사용률이 0.98로 보고됐다. 실제 시험 전에 한도 여유를 확인한다.

# 실행 방법 (가장 쉬운 순서)

## 0. 준비물
- **Python 3.9 이상** 설치 → https://www.python.org/downloads/
  - Windows 설치 시 **"Add Python to PATH"** 체크 꼭 켜기
- 인터넷 연결 (처음 한 번 패키지 다운로드)

## 1. 코드 내려받기
GitHub PR 페이지에서 코드를 받으세요.
- 브랜치: `claude/ibox-product-detection-3432uk`
- 방법 A: `git clone` 후 브랜치 체크아웃
  ```bash
  git clone https://github.com/kavalriero-star/-.git
  cd -/
  git checkout claude/ibox-product-detection-3432uk
  cd ibox_inspector
  ```
- 방법 B: GitHub에서 해당 브랜치를 **"Download ZIP"** 으로 받아 압축 해제 후
  `ibox_inspector` 폴더로 이동

## 2. 실행 (원클릭)
- **Windows**: `ibox_inspector` 폴더의 **`run.bat`** 더블클릭
- **macOS / Linux**: 터미널에서
  ```bash
  cd ibox_inspector
  bash run.sh
  ```
처음 실행 시 가상환경 생성 + 패키지 설치(수 분 소요) 후 **GUI 창**이 열립니다.

## 3. GUI 사용법
- **[이미지 검사] 탭**: `이미지 열기` → 사진 선택 → 칸별 있음(O)/없음(X) 결과 표시
  - 바로 테스트하려면 `data/samples/box.jpg` 를 열어보세요.
- **[실시간 카메라] 탭**: 카메라 번호 선택 → `시작` → 실시간 판정
- 상단 슬라이더로 검출 민감도(임계값) 조절

## 명령줄로만 빠르게 확인 (GUI 없이)
```bash
pip install -r requirements.txt
python -m src.inspect_image --image data/samples/box.jpg
```
→ 콘솔에 칸별 결과, `data/samples/box.result.jpg` 에 시각화 이미지 저장.

## 참고
- 처음엔 학습 모델이 없어 **자동 백업 판정(파란 박스 vs 제품 색 구분)** 으로 동작합니다.
  실제 환경에 맞춰 정확도를 높이려면 `README.md` 의 "커스텀 학습" 을 따라 하세요.
- 카메라/박스 위치가 다르면 격자 보정이 필요합니다:
  ```bash
  python -m src.calibrate_grid --image data/samples/box.jpg --rows 4 --cols 4
  ```
  박스 안쪽 네 모서리를 좌상→우상→우하→좌하 순서로 클릭하고 `S` 로 저장.

# Claude PowerPoint 애드인 워크플로우

AI 도구(NotebookLM + Claude 파워포인트 애드인)를 조합하여 비즈니스 슬라이드를 효율적으로 제작하는 가이드입니다.

## 구성

- `guide/claude-powerpoint-addon-workflow.md` - 전체 워크플로우 가이드
- `guide/prompts/style-extraction-prompt.md` - 프롬프트 모음

## 핵심 워크플로우

1. **NotebookLM** - Deep Research로 보고서 요약 → 초안 PPT 생성
2. **Claude 애드인** - 회사 템플릿 스타일 추출 → 초안에 서식 일괄 적용
3. **PowerPoint** - 이미지 마스킹, 레이아웃 조정으로 최종 완성

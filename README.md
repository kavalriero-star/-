# Pixel Office AI — Living Office

가상 사무실에서 일하는 16명의 픽셀 아트 직원들이 AI로 구동되는 프로젝트입니다.
40×26 타일 맵, 9개 방, BFS 길찾기, 자율 행동, 부서별 업무 체인, 낮/밤 주기를 포함합니다.

## 주요 기능

- **16명의 직원**: CEO, PM, 개발자, 디자이너, QA, 영업, 구매, 제조, 인사, 재무, 리셉션
- **9개 방**: CEO 집무실, 회의실, 프레젠테이션룸, 로비, 휴게실, 발코니, 서버룸, 화장실, 개방형 사무공간
- **자율 행동**: 에이전트가 점심/휴식/화장실/산책 등 자율적으로 행동
- **부서별 업무 체인**: 부서 선택 후 업무 입력 → 관련 직원들이 순차적으로 작업 → QA 검사 → CEO 승인
- **Claude AI 연동**: ANTHROPIC_API_KEY 설정 시 실제 AI가 각 직원의 업무 결과를 생성
- **낮/밤 주기**: 시간에 따라 조명, 창문 빛줄기, 먼지 파티클 등 변화
- **Tweaks 패널**: 시간 속도, 조명, 자율 행동, BGM, 레이아웃 설정

## 기술 스택

| 영역 | 기술 |
|------|------|
| 프론트엔드 | Phaser.js 3, Pretendard 폰트, Iconify |
| 백엔드 | Node.js, Express, Socket.io |
| AI | Anthropic Claude API |
| 에셋 | 브라우저 내 Canvas로 프로그래매틱 생성 |

## 빠른 시작

```bash
npm install
cp .env.example .env    # ANTHROPIC_API_KEY 설정 (없어도 Mock 모드로 동작)
npm start
```

브라우저에서 `http://localhost:3000` 접속

# 엘레멕 원가계산 프로그램

삼성SDI 부품(U6A5 · U8A1 INNER COVER ASS'Y) 견적 검토 엑셀의 **제조원가 테이블**
계산 로직을 그대로 재현한 웹 기반 원가계산 프로그램입니다.
사출품 → 조립품 원가를 상향식으로 롤업하여 **제조원가**와 **판가**를 산출하고,
시나리오·경쟁사 비교·손익분기(BEP) 분석과 **엑셀 출력**을 제공합니다.

> 원본: `SDI U6A5/U8A1 Inner Cover Ass'y 견적검토 2600723 R6`
> 엔진 계산값은 원본 엑셀의 제조원가·판가와 **오차 0.5원 이내로 일치**함을 테스트로 검증합니다.

## 빠른 시작

```bash
pip install -r requirements.txt
python app.py
# 브라우저에서 http://127.0.0.1:5000
```

의존성: Flask, openpyxl (계산 엔진 자체는 표준 라이브러리만 사용).

## 주요 기능

| 화면 | 설명 |
|------|------|
| **견적 요약** | 품목별 제조원가·판가·매출(월/년), 연간 매출 KPI |
| **원가 상세** | 재료비(A)/노무비(B)/제조경비(C)/제조원가(D) 편집·실시간 재계산, 산출근거 드릴다운, 구성비 시각화, 판가 산출 |
| **판가 시나리오** | 영업이익율 × 관리비율 판가 민감도 매트릭스(현재 견적값 강조) |
| **경쟁사 비교** | 당사 견적가 vs 신흥정밀 양산판가 차이(원/%) |
| **손익 · BEP** | 고정/변동비 분해, 개당 공헌이익, 손익분기 물량·매출 |
| **마스터** | 설비 기준표(톤수별), 인건비표, 공통 상수/율 |
| **엑셀 출력** | 견적요약 + 품목별 제조원가 테이블 + 시나리오 + 경쟁사 + BEP (6종 시트) |

**다중 견적(프로젝트) 관리**: 상단 `＋ 새 견적`으로 **백지에서 새 원가 견적을 생성**하고,
여러 견적을 저장·전환·이름지정·삭제할 수 있습니다(브라우저 localStorage). 기존 SDI 견적은
샘플로 유지되며, 앱이 특정 데이터에 고정되지 않습니다.

**신규 모델(품목) 추가**: 사이드바 `＋` 버튼으로 신규 사출품·조립품을 추가하고,
기존 품목 **복제**·**삭제**(실행취소 지원)가 가능합니다. 조립품은 재료 유형을 **사출품 참조**로
바꿔 다른 사출품 원가를 재료비로 롤업할 수 있습니다.

추가 UX: 실시간 재계산(편집 중 포커스 유지), 라이트/다크 테마, 저장·불러오기(JSON),
브라우저 자동 복원(localStorage), 입력검증(잘못된 값은 명확한 한국어 메시지),
**대량입력**(Enter/방향키 셀 이동, 엑셀 표 붙여넣기), 유효성 경고 배지, 인쇄(A4) 대응.

## 원가 계산 모델

```
재료비(A) + 노무비(B) + 제조경비(C) + LOSS = 제조원가(D)
판가 = 제조원가 × (1 + 관리비율 + 영업이익율) + 운반비
```

2단계 롤업: **사출품 제조원가 → 조립품 재료비(A)로 투입 → 조립품 제조원가 → 판가**

- 일 Capa = 작업시간/교대 × 교대수 × 3600 ÷ CT(초) × 효율 × (cavity | 라인수)
- 재료비: 사출원재료 `중량(g)×단가(원/kg)÷1000`, Insert/지정도급 `수량×단가`,
  버스바 `수량×(기준단가×0.9)`, 조립 사출품 `사출품 제조원가×수량`
- 노무비: `(총투입인원×교대)×임율 ÷ 일Capa`, 간접노무비 = 직접 × 30%
- 제조경비: 설비·건물·전용설비 감가, 복리후생(노무비×15%), 수도광열, 소모품(0.5%),
  수선비, Setting, (조립) 포장비, 기타(0.5%)

자세한 내용은 [`docs/cost_model.md`](docs/cost_model.md) 참조.

## 프로젝트 구조

```
app.py                     Flask 서버 / REST API
costcalc/
  engine.py                원가 계산 엔진(제조원가·판가)
  analysis.py              시나리오·경쟁사·BEP 분석
  standards.py             마스터 데이터 로더(설비 기준표 VLOOKUP 대체)
  validate.py              입력 검증
  excel_export.py          openpyxl 엑셀 출력
  data/
    build_seed.py          시드 데이터 생성기(6품목)
    config.json            전사 공통 상수/율
    equipment_standards.json  설비 기준표
    labor_rates.json       근무형태별 인건비
    products.json          품목별 견적 파라미터
web/                       프론트엔드(index.html + css + js, 빌드 불필요)
tests/                     엔진·검증 테스트(pytest)
```

## 테스트

```bash
python -m pytest tests/ -v
```

- `test_engine.py` : 4개 사출품·4개 조립품 제조원가 및 판가가 엑셀 실제값과 일치하는지 검증
- `test_validation.py` : 경계조건(0 CT, 0 물량, 미등록 톤수, 참조 오류 등) 검증

## 마스터 데이터 관리

- 설비/인건비/공통상수 등 **마스터**는 관리자 항목이며 버전(`config.version`)이 부여됩니다.
- 견적담당이 자주 바꾸는 값(톤수·CT·효율·재료단가·물량·이익율 등)은 화면에서 직접 편집합니다.
- 시드 값 재생성: `python costcalc/data/build_seed.py`

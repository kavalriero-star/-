## 1. 준비 단계: 애드인 설치

### 설치
- MS 마켓플레이스에서 **'Claude by Anthropic in PowerPoint'** 검색 후 설치

### 연결
- 파워포인트 실행 → 오른쪽 상단 **클로드 아이콘** 클릭 → 로그인
- **유료 버전(Pro 이상)** 필요

---

## 2. 소스 생성: NotebookLM 활용

### 내용 정리
- NotebookLM의 **'Deep Research'** 기능으로 보고서 내용을 슬라이드용으로 요약
- 예: 7페이지 구성

### 초안 제작
1. 요약된 내용을 소스로 등록
2. **'슬라이드 덱'** 메뉴에서 상세 요청 입력:
   - 작성 언어 (예: 영어)
   - 배경색
   - 액센트 컬러
   - 기타 디자인 요소
3. 초안 PPT 생성 후 다운로드

---

## 3. 서식 적용: Claude 애드인 활용

### 회사 서식 학습
1. 회사 표준 템플릿 슬라이드를 **캡처**
2. Claude 애드인에 이미지를 업로드
3. 프롬프트: `"이 페이지의 스타일 시트를 추출해줘"`

### 스타일 시트 & 프롬프트 템플릿
Claude가 분석하여 제공하는 항목:

| 구분 | 내용 |
|------|------|
| **스타일 시트** | 폰트, 색상, 위치 규칙 |
| **프롬프트 템플릿** | 텍스트 길이, 구조 규칙 |

> 추출된 스타일 시트와 프롬프트 템플릿을 **복사하여 보관**해두면 재사용 가능

### 일괄 적용
- NotebookLM 초안 슬라이드에 스타일 시트 + 템플릿을 적용
- 회사 서식에 맞게 **일괄 재생성**

---

## 4. 시각화 및 편집: 파워포인트 스킬

### 이미지 마스킹
NotebookLM이 생성한 이미지에서 텍스트를 제외하고 이미지만 추출하는 방법:

1. **자유형 도형**으로 원하는 영역을 그림
2. 이미지와 도형을 모두 선택
3. **도형 병합 → 교차** 기능 사용
4. 깔끔하게 잘린 이미지 획득

### 레이아웃 조정
- 텍스트 박스에 자동 입력된 내용 배치
- 잘라낸 이미지를 적절히 배치
- 최종 슬라이드 완성

---

## 5. 추가 팁

### 표지 생성
- **Gemini** 등 다른 AI를 활용하여 기존 보고서 표지를 특정 스타일로 변형 가능
- 예: 폴리곤 스타일로 전문적인 느낌 추가

### 핵심 원칙
> 각 AI가 잘하는 분야를 조합하여 실수 없이 완벽한 비즈니스 슬라이드를 제작
>
> - **NotebookLM**: 정보 수집 및 요약 (정보력)
> - **Claude**: 분석 및 코딩 (스타일 추출/적용)
> - **Gemini**: 이미지 생성 및 변형

```
    │
    ▼

    │
    ▼

    │
    ▼
[PowerPoint 편집] ─→ 이미지 마스킹, 레이아웃 조정
    │
    ▼
[최종 슬라이드 완성]
```

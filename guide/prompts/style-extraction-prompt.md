# 스타일 추출 프롬프트 모음

Claude PowerPoint 애드인에서 사용할 수 있는 프롬프트 예시입니다.

## 스타일 시트 추출

### 기본 추출
```
이 페이지의 스타일 시트를 추출해줘
```

### 상세 추출
```
이 슬라이드의 디자인 요소를 분석하여 다음 항목을 추출해줘:
- 사용된 폰트 (이름, 크기, 굵기)
- 색상 팔레트 (배경, 텍스트, 액센트)
- 요소 위치 및 간격 규칙
- 텍스트 정렬 방식
```

## 서식 적용

### 일괄 적용 프롬프트
```
다음 스타일 시트를 현재 슬라이드에 적용해줘:
[스타일 시트 내용 붙여넣기]
```

### 텍스트 구조 규칙 적용
```
다음 프롬프트 템플릿에 맞게 현재 슬라이드의 텍스트를 재구성해줘:
- 제목: 최대 10단어
- 본문: 불릿 포인트 3~5개
- 각 불릿: 최대 15단어
[프롬프트 템플릿 내용 붙여넣기]
```

## NotebookLM 슬라이드 덱 요청 예시

```
이 내용을 7페이지 슬라이드 덱으로 정리해줘:
- 언어: 영어
- 배경색: #1a1a2e
- 액센트 컬러: #e94560
- 폰트: 깔끔한 산세리프
- 각 슬라이드에 핵심 메시지 1개
- 데이터는 차트/그래프로 시각화
```

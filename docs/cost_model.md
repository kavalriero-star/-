# 원가 계산 모델 상세

본 문서는 견적 검토 엑셀 `SDI U6A5/U8A1 Inner Cover Ass'y 2600723 R6`의
**제조원가 테이블**을 역설계한 계산 모델을 정의한다. 엔진(`costcalc/engine.py`)은
이 모델을 그대로 구현하며, 산출값은 원본 엑셀과 오차 0.5원 이내로 일치한다.

## 1. 대상 품목

| 구분 | 품목 | 자재코드 | 월물량 |
|------|------|----------|--------|
| 조립 | U6A5 Inner Cover ASSY A | V045-0126AA | 20,000 |
| 조립 | U6A5 Inner Cover ASSY B | V045-0125AA | 20,000 |
| 조립 | U8A1 ASSY Holder BUSBAR A (슈나이더外/向) | V045-0158AA/0187AA | 2,500 × 2 |
| 조립 | U8A1 ASSY Holder BUSBAR B (슈나이더外/向) | V045-0159AA/0188AA | 2,500 × 2 |
| 사출 | Inner Cover A/B (A5) | V143-00042A/00041A | 20,000 |
| 사출 | Holder BUSBAR A/B (U8) | - | 5,000 |

조립품은 대응하는 사출품을 재료로 포함한다(2단계 롤업).

## 2. 계산 흐름

```
                        ┌─ 재료비(A)  ┐
   [사출품]  파라미터 ──┼─ 노무비(B)  ┼─→ 제조원가 = A+B+C+LOSS
                        └─ 제조경비(C)┘            │
                                                    ▼ (재료비로 투입)
                        ┌─ 재료비(A) ← 사출품원가 ┐
   [조립품]  파라미터 ──┼─ 노무비(B)              ┼─→ 제조원가 ─→ 판가
                        └─ 제조경비(C)            ┘
```

**판가 = 제조원가 × (1 + 관리비율 + 영업이익율) + 운반비**

## 3. 공통식

- **일 Capa[설비당]** = 작업시간/교대 × 교대수 × 3600 ÷ CT(초) × 효율 × (cavity | 라인수)
  - 예) 사출 450톤: 12 × 2 × 3600 ÷ 50 × 0.9 × 1 = **1,555.2**
  - 예) 조립: 10.5 × 1 × 3600 ÷ 15 × 0.9 × 1 = **2,268**
- **임율** = 2교대 일당 = 182,806.46원/일 (근무형태별 인건비표 기준)

## 4. 재료비(A)

| 유형 | 산식 |
|------|------|
| 사출 원재료(net) | 중량(g) × 단가(원/kg) ÷ 1000 |
| Insert·지정도급(qty) | 수량 × 단가(원/EA) |
| 버스바(busbar) | 수량 × (기준단가 × 0.9) |
| 사출품(part_ref) | 수량 × 사출품 제조원가 |

## 5. 노무비(B)

- 직접노무비 = (Σ 투입인원 × 교대수) × 임율 ÷ 일Capa
- 간접노무비 = 직접노무비 × 30%
- 노무비(B) = 직접 + 간접

## 6. 제조경비(C)

### 사출품
| 항목 | 산식 |
|------|------|
| 설비 감가 | 투자비감가(기준표, 원/일) ÷ 일Capa |
| 전용 설비 | 전용설비 합계 ÷ (기준물량/월 × 12 × 3년) |
| 건물 감가 | 건물감가(기준표, 원/일) ÷ 일Capa |
| 복리후생비 | 노무비 × 15% |
| 수도광열비 | 전력비(기준표, 원/일) ÷ 일Capa |
| 소모품 | (재료비 + 노무비) × 0.5% |
| 수선비 | 수선비(기준표, 원/일) ÷ 일Capa |
| Setting | [Setting비용 + 원재료단가 × 퍼지용량 + 재료비 × 5] ÷ 월물량 |
| 기타 | (재료비 + 노무비) × 0.5% |

### 조립품
| 항목 | 산식 |
|------|------|
| 전용 설비 | 전용설비 합계 ÷ (50,000/월 × 12 × 3년) |
| 건물 감가 | 제조면적(500㎡) × 건물단가(원/㎡·일) ÷ 일Capa |
| 복리후생비 | 노무비 × 15% |
| 수도광열비 | 전력량(87kW) × 180 × 12 × 0.5 ÷ 일Capa |
| 소모품 | (재료비 + 노무비) × 0.5% |
| 수선비 | 전용설비감가 × 6% |
| 포장비 | 단프라 + 비닐 + 니트롱지 + 파렛트 (안분) |
| 기타 | (재료비 + 노무비) × 0.5% |

## 7. 제조원가(D) / 판가

- **LOSS** = (A + B + C) × LOSS율 (사출 3%, 조립 1%)
- **제조원가** = A + B + C + LOSS
- **운반비** = 1회운임(700,000원) ÷ (총적재수량 × 용적율 0.9) = 462.96원/EA
- **판가** = 제조원가 × (1 + 관리비율 + 영업이익율) + 운반비
- 매출/월 = 판가 × 물량, 매출/년 = × 12

## 8. 손익분기(BEP) 분류

| 성격 | 항목 |
|------|------|
| 변동비 | 재료비, 복리후생비, 수도광열비, 소모품, 포장비, 운반비, LOSS |
| 고정비 | 설비·건물·전용설비 감가, 수선비, 기타, 관리비 |

- 개당 공헌이익 = 판가 − 개당 변동비
- BEP 물량 = 월 고정비 총액 ÷ 개당 공헌이익

> 노무비는 원본 엑셀 가정에 따라 기본 전액 변동비로 처리하되,
> `bep_analysis(labor_fixed_ratio=...)` 로 상주인력(고정) 비율을 조정할 수 있다.

## 9. 도메인 검토 시 유의점 (원가 전문가 자문)

원본 로직을 충실히 재현하되, 다음 항목은 개선 여지가 있어 **파라미터로 외부화**하였다
(마스터 `config.json` 및 품목별 값에서 조정 가능):

1. **소모품·기타 동일 산식**: 둘 다 (A+B)×0.5% 로 성격이 겹친다. 율을 분리하거나 통합 검토.
2. **LOSS를 A+B+C 전체에 적용**: 재료 스크랩 성격이면 재료비(A)에만 적용하는 것이 정석.
3. **노무비 전액 변동 가정**: 2교대 상주인력은 준고정비 → BEP는 `labor_fixed_ratio`로 보정.
4. **전용설비 감가 기준물량(사출 2.5만 vs 조립 5만)**: 대응 생산물량 근거를 문서화 필요.
5. **간접노무비 일괄 30%, 버스바 0.9 할인**: 공정 성격·사급 근거를 확인·문서화.

이들 상수는 하드코딩하지 않고 마스터에서 주입되므로, 정책 변경 시 코드 수정 없이 반영된다.
